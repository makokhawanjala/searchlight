# SearchLight 🔦

A lightning-fast file search engine with web GUI, inspired by "Everything" for Windows.

## Features (In Development)
- ⚡ Concurrent file indexing with worker pools
- 🔍 Multiple search types: prefix, substring, wildcard, regex, fuzzy
- 🌐 Modern web interface with real-time updates

## Tech Stack
- **Language:** Go 1.21+
- **Web:** net/http, WebSockets, HTML templates

## Project Status
🚧 Phase 1/17 - Basic HTTP server complete

## Current Progress
✅ Phase 1-9 Complete (Nov-Dec 2025)
- Configuration system with multi-source loading
- Concurrent file indexing with worker pools

- Persistent storage with atomic saves
